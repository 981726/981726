### `01 / about`

I'm into the technical side of things — figuring out what makes software tick, testing different configurations and seeing what can be improved.

- Building Discord bots, utilities and automation tools.
- Tweaking Windows to reduce unnecessary resource usage without sacrificing stability.
- Experimenting with NIC drivers, network settings and connectivity.
- Making optimization scripts and messing around with system configurations.
- Playing Jailbreak and occasionally getting distracted by a random coding idea.

I don't stick to one thing for too long. If something interests me, I'll probably end up testing it, scripting it or trying to improve it.
